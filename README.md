# Academia ABC - GitHub Pages

Site estatico pronto para publicar. Todos os videos ficam em arquivos MP4 separados de index.html, mas hospedados no mesmo repositorio, sem links externos ou configuracao adicional.

## Publicar no GitHub pelo navegador

1. Crie um repositorio PUBLICO novo no GitHub (por exemplo, academia-abc).
2. Extraia este ZIP no seu computador.
3. No repositorio, clique em Add file > Upload files e envie o CONTEUDO extraido (index.html, video-config.js, .nojekyll e as pastas img, posters e videos). Nao envie o ZIP fechado. Se o navegador nao permitir pastas, use GitHub Desktop para publicar a pasta extraida.
4. Em Settings > Pages, escolha Deploy from a branch, branch main, pasta /(root), e salve.
5. Acesse o endereco exibido em Settings > Pages depois da publicacao.

## Observacoes

- O site e os videos ficam PUBLICOS na internet. Nao coloque informacoes confidenciais nos videos.
- Cada video e menor que 25 MB, adequado ao upload individual pelo navegador. O repositorio inteiro tem aproximadamente 102 MB.
- O player usa caminhos relativos em videos/, sem modificar a aparencia do site.
- Nao altere a estrutura de pastas.
