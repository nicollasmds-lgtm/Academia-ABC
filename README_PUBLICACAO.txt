ACADEMIA ABC - PUBLICACAO NO GITHUB PAGES

1. Extraia o ZIP.
2. Copie index.html e as pastas videos, img e posters diretamente para a raiz do repositorio Academia-ABC.
3. No GitHub Desktop, faca Commit to main e Push origin.
4. Em Settings > Pages, configure main / (root).
5. Aguarde a publicacao e recarregue o site com Ctrl+F5.

Importante: o ZIP nao deve ser enviado fechado, e a pasta site nao deve ser criada na raiz.
Todos os 21 arquivos MP4 precisam estar em videos/ ao lado de index.html.
Se algum video falhar, confira no navegador a URL https://nicollasmds-lgtm.github.io/Academia-ABC/videos/elaboracao-de-contrato-de-representacao.mp4
